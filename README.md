# Paper Deep Reading · 文献精读与证据链审查

把科研论文拆解成可追溯的论证链。从作者如何提出问题开始，逐步解释数据和方法，逐图逐表核查结论，再把证据缺口转化为可检验的后续研究。默认用中文输出，保留关键英文术语和原文图表编号。

## 快速开始

### Codex

1. 下载或克隆本仓库，把完整的 [`paper-deep-reading/`](paper-deep-reading/) 目录复制到个人技能目录。Windows 可用 `%USERPROFILE%\.codex\skills`，macOS 或 Linux 可用 `~/.codex/skills`。如果你配置了 `CODEX_HOME`，使用其下的 `skills` 目录。
2. 在 Codex 中提供论文 PDF 和可获得的补充材料，发送下面的指令。

   ```text
   请用 $paper-deep-reading 精读这篇论文，逐图逐表核查证据链，并提出可证伪的后续研究设计。
   ```

### 豆包、DeepSeek 等聊天助手

1. 打开[通用提示词](paper-deep-reading-prompt.md)，复制全文到新对话。
2. 附上论文 PDF，或粘贴正文、图注和表格。发送「请按以上要求完整精读这篇论文」。
3. 如果助手只能读到 PDF 提取的文字，补充对应图表的清晰截图及图注。长论文可以分批读，在同一对话中回复「继续」。

也可以指定范围，例如「先读图 2 和图 3，判断它们是否支持作者的因果解释」。

## 报告内容

| 部分 | 会回答的问题 |
| --- | --- |
| 研究背景 | 已有哪些认识，缺口是什么，作者如何提出研究问题和假设？ |
| 数据选择 | 数据从哪里来，为什么选它，优势和适用边界是什么？ |
| 研究思路 | 研究路线图如何串联数据来源、并行分析、中间结果和结论？论文发表前，主流方法如何解决同一问题？本文改动了哪一步，替代方法会带来什么变化？ |
| 逐图逐表解读 | 为什么做，怎么做，坐标、分组和误差条怎么看，得到了什么结果，又如何引出下一张图？ |
| 证据链核查 | 核心主张由哪些图表或分面支撑？图表之间是否存在冲突或推理缺口？ |
| 事实与解释 | 哪些是原文报告的事实，哪些是作者的解释，哪些是进一步推断？ |
| 后续研究 | 可以检验什么假设，需要哪些对照、数据和分析方法，什么结果会推翻假设？ |

每项核心结论会标为 **成立**、**特定条件下成立** 或 **未被证实成立**，并给出原文位置和判定理由。报告会结合效应量、不确定性、研究设计和偏倚评估结论。无法查看的图表会标为 **未核验**，并注明需要补充的材料。
